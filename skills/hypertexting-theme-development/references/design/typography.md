# Typography

## Overview

Typography establishes hierarchy and reading comfort across the complete theme.
Choose font roles, scale, measure, and rhythm from the supplied visual direction
before assigning individual page styles.

## Instructions

- Use one or two font families unless the supplied direction demonstrates a clear role for more.
- Define separate roles only when needed: display, body, UI, and code.
- Define a consistent heading hierarchy, body size, supporting text, caption, and metadata treatments.
- Set readable line lengths and line heights for long-form content.
- Scale typography responsively without making narrow viewports difficult to read or operate.
- Preserve semantic heading order; visual treatment must not replace document hierarchy.
- Test long titles, long labels, URLs, and non-English text against the type system.

## Examples

| Role | Purpose |
| --- | --- |
| display | page and section introductions |
| body | sustained reading |
| UI | navigation, buttons, and controls |
| supporting | captions, metadata, and helper text |

## Specification

Consult `hypertexting-html` for semantic heading and text markup, and `hypertexting-css` for the CSS implementation.
