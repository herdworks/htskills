# HyperTexting

## Overview

HyperTexting is a data-driven website management system that combines file-based content management with a static site generator (SSG) to create, deploy, and update websites.

It uses a pure-HTML templating and theme-management system called HyperTemplates to generate websites from a website configuration file, a theme, and a repository of data files.

HyperTexting is available as a native app for iPhone, or a CLI called `hyperctl` for Mac, Linux, and Windows.
